# 通用项目：Python 定时数据管道 → 每日报告

## 目标

- 每天定时拉取数据、生成 HTML 报告。
- 报告作为 Artifact 保留 30 天。
- 无论成功失败都推送企业微信通知。

## 文件

```
.github/workflows/daily.yml
```

## 需要配置的 Secrets

| 名称 | 用途 |
| --- | --- |
| `API_KEY` | 数据源密钥 |
| `DB_URL` | 数据库连接串 |
| `WECOM_WEBHOOK` | 企业微信群机器人 Webhook 地址 |

## 注意事项

- **时区**：`cron` 使用 UTC。北京时间 09:00 对应 `0 1 * * *`。
- **只在默认分支运行**：`schedule` 事件要求工作流文件存在于默认分支，修改后需合并到默认分支才生效。
- **可能延迟**：GitHub 高负载时定时任务会延迟数分钟，不要当作精确调度器。
- **60 天规则**：仓库连续 60 天无活动，定时任务会被自动禁用。
- 两个 `if: always()` 保证失败时仍能上传产物并发出通知，便于快速定位问题。
- 需要分钟级精度或自动重试时，改用外部调度器触发 `workflow_dispatch`。
